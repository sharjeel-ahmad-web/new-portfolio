## 🚀 How to Get Started (Next 10 Minutes)

### **Step 1: Environment** (2 min)
```bash
cp .env.example .env.local

# Add these values:
# EMAIL_USER=your-email@gmail.com
# EMAIL_PASSWORD=your-app-password (from Gmail)
# ALERT_EMAIL=chjiimy@gmail.com
```

### **Step 2: Install** (1 min)
```bash
npm install
```

### **Step 3: Test Locally** (2 min)
```bash
npm run dev
# Open http://localhost:3000
# Click chat widget, send message
# Check email inbox
```

### **Step 4: Build** (2 min)
```bash
npm run build
# Verify: "✓ build is complete"
```

### **Step 5: Deploy** (3 min)
```bash
git push
vercel deploy
# Add env variables in Vercel dashboard
```
